- **2026-11-14 — Map list cannot switch the displayed map after parent/child zoom navigation; dungeon inaccessible.** After the two checks above, user reports that zooming through parent/child relationships leaves map-list navigation unable to reach other maps, including the standalone dungeon. Source confirms a state mismatch: Maps-panel clicks only update global `activeMapId`, while the map renderer prefers its explicit `panelState.mapId`; zoom transitions set that panel-specific map. Subsequent map-list clicks do not clear or replace it. The visible map can therefore stay on a parent/child despite a different globally selected map. Record as a navigation blocker and inspect map-dependent editing panels for consistent targeting later. The report indicates inaccessible content, not confirmed deletion. Notes only; no navigation fix or live-world changes.
